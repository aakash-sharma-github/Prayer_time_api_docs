# API Reference

## API version

This documentation targets **v1**. All public endpoints use the `/api/v1/` prefix.

## OpenAPI strategy

FastAPI remains the source of truth for parameters, schemas, constraints, defaults,
and error responses. Run `npm run sync:openapi` against a local or deployed API to
save its current schema at `public/openapi.json`. Future reference rendering will read
that schema instead of manually duplicating the contract.
