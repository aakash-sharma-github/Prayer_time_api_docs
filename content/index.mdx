# azanAPI

A REST API for calculating Islamic prayer times.

Accurate prayer-time calculations with configurable calculation methods, Madhab
settings, timezones, high-latitude rules, and Azan adjustments.

## Start here

- [Get started](/getting-started)
- [API reference](/api-reference)

## Documentation foundation

This site establishes the public documentation architecture for azanAPI. The API
reference will be derived from the FastAPI OpenAPI contract, while the guides explain
how and why to use the API.
